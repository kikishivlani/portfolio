## Projects

### [Clinical Trial Finder](./clinical-trial-finder)
A web app built with Streamlit that helps users search and filter clinical trials from ClinicalTrials.gov by age, sex, and condition.
**Tools:** Python, Streamlit, ClinicalTrials.gov API

### [Bellabeat Fitbit Analysis](./bellabeat-fitbit-analysis)
Google Data Analytics Capstone project analyzing Fitbit fitness tracker data to uncover activity and sleep trends, translated into marketing recommendations for Bellabeat's Leaf tracker. Includes a full interactive Tableau dashboard.
**Tools:** SQL (BigQuery), Tableau
