# Kiki Shivlani — Portfolio

Neuroscience graduate with a focus on healthcare, research, and data analysis. This repo collects my data analytics case studies and projects, with a particular interest in healthcare, biotech, and public health data.

---
## Projects

### [Clinical Trial Finder](clinical-trial-finder)
A web app built with Streamlit that helps users search and filter clinical trials from ClinicalTrials.gov by age, sex, and condition. **Tools:** Python, Streamlit, ClinicalTrials.gov API

### [Bellabeat Fitbit Analysis](bellabeat-fitbit-analysis)
Google Data Analytics Capstone project analyzing Fitbit fitness tracker data to uncover activity and sleep trends, translated into marketing recommendations for Bellabeat's Leaf tracker. Includes a full interactive Tableau dashboard. **Tools:** SQL (BigQuery), Tableau

### [Alzheimer's Risk Factor Analysis](alzheimers-risk-analysis)
Self-directed case study analyzing demographic, lifestyle, and clinical predictors of Alzheimer's diagnosis. Compares a risk-factor-only model (AUC 0.52) against a cognitive/functional-assessment model (AUC 0.89) to test what actually predicts diagnosis, with a threshold-tuned recommendation for early-detection screening. **Tools:** Python, scikit-learn, Tableau
